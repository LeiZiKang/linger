# 余音官网演示 / Linger web demo

两首约 60 秒的演示曲目、歌词和配色均为本演示新写。`audio: null` 时浏览器用 WebAudio 合成和弦、贝斯与轻鼓点，没有人声，没有采样或真实歌曲素材。歌词按 64 BPM、每句两小节对齐；它是伴奏上的视觉跟唱演示。无需构建、第三方库或 CDN。请通过静态 HTTP 服务预览，不能直接双击 file:// 读取 JSON。

## 换成自己的歌

1. 只使用自己拥有或明确获准商用、公开分发的音乐、歌词及翻译。不要模仿特定歌手或歌曲。
2. 音频放入 `site/demo/audio/`。建议 60～90 秒、128kbps MP3，每首不超过 3MB。
3. 通过同一静态服务器打开 `site/demo/timing.html`（不在导航链接中，带 noindex）。选择本地音频、填曲名和 BPM、粘贴歌词，每行 `原文 | 翻译`。音频只从本地 Blob 读取，不上传。
4. 载入歌词后播放，聚焦打轴区：Space 记录一个中文字或英文单词的起点；全部打完后按 Enter 记录该句终点并进入下一句。可选 0.5 倍速，可回退一步，再拖动原生音频进度重打。导出前必须完成所有句子。
5. 把导出的曲目对象加入 `tracks.json` 数组，或替换已有对象。`audio` 路径相对于 `tracks.json`，例如 `audio/my-original.mp3`；三个 palette 色值决定封面和流光。歌词的全部起止时间单位为秒，不能超出音频长度。
6. 在 `audio/LICENSE.txt` 记录音频、歌词、翻译的来源、作者、生成服务/方案（如适用）、商用及公开分发授权条款链接、取得日期和授权凭据位置。不要把支付信息或密钥放到网站。
7. 在项目目录运行 `node site/demo/validate-tracks.js`；更新前后分别听一遍并检查拖进度、暂停、切歌。再运行 `node --check` 检查各 JS。真实浏览器观感由 Claude 验收。

## 控制

桌面端播放器与卡片可以拖动；方向键移动，卡片 Shift+方向键缩放，右下角缩放按钮也支持方向键。低矮卡片只保留当前句和翻译。工具条可锁定穿透、切换最前/桌面层，锁定时工具条仍可操作。最前层悬停时内容变淡。播放时凝聚，暂停 1.2 秒后从边缘溶解。窄于 820px 只保留卡片、播放和进度。

焦点在演示区内时空格可切换播放（按钮及输入框保留原生键盘行为）。切换到后台标签页会暂停且不自动恢复；滚出首屏只停止视觉帧，声音继续，滚回来可以暂停。减少动态效果设置关闭流光运动与文字上浮，溶解改为淡出。合成器使用 AudioContext 时钟；文件音乐使用 audio.currentTime，两者向渲染器提供同一接口。播放完自动下一首，声音具有约 0.8 秒淡入淡出。
